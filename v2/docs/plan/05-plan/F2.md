- **Depende de**: T-201
- **Épica**: E-QWE-1
- **Estado**: [x] **Hecho**
- **Entregable / definición de terminado**: El prompt corto devuelve la decisión en 3 salidas (comprobante / no comprobante / indeterminado) sobre la vista rápida.
- **Implementación**: `validation/qween.py` (`decidir_es_comprobante`) + `validation/prompt_qween.py` (prompt versionado `qween-gate@2`). Tests: `tests/test_validation_qween.py`.
